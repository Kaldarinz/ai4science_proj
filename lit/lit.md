# Paper references

Add 5–10 relevant references. Start with `results/sources.csv`, local
`notes/Source *.md`, `data/corpus.csv` and the supplied PDFs. These records
are leads, not proof of a paper's findings. For each citation, verify the
bibliographic metadata against the publisher or OpenAlex using evidence
provided by the curator if it is not already available locally. Keep a
text location (page, figure, table or abstract), what the cited evidence
supports and how the current work differs. Do not attribute full-text
findings to an abstract-only record.

Use the same key in `paper/paper.tex` (both `\cite` and `\bibitem`).
