# Проверить закон Аррениуса в 25-70 C

Готово, когда: линейная регрессия ln k от 1/T по сериям 2024-01, 2024-02, 2024-04 даёт R² ≥ 0.99; результат записан в results/.
Не входит: серия 2024-03.

## Итог
Линейная регрессия ln k от 1/T по 15 точкам серий 2024-01, 2024-02, 2024-04 (серия 2024-03 исключена) даёт R² = 0.9993 ≥ 0.99 — разложение подчиняется закону Аррениуса в интервале 25–70 °C. Проверено командой `python3 src/arrhenius_fit.py`, результат в [[results/arrhenius_fit.csv]].
